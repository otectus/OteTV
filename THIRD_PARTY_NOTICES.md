## Required at runtime but not distributed with the mod

### GStreamer

Used by the media worker through the player's system installation (Linux distribution packages, or the official
GStreamer installer on Windows). GStreamer core and base plugins are LGPL-2.1-or-later; other plugin sets
(good, bad, libav/FFmpeg) carry their own licenses and, for some codecs, patent considerations in some countries.
OteTV does not ship GStreamer. If a GStreamer runtime bundle is ever published for OteTV, it must include a per-plugin
license inventory and the corresponding source offer.
