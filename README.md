# OteTV

Televisions for Minecraft 1.20.1 (Forge 47): six models from the 1950s to today, a universal remote, server channels,
and synchronized playback that every player's own computer decodes. Direct media plays through an out-of-process
GStreamer worker; YouTube plays through the official embedded player in a sandboxed native browser worker.

OteTV is an independent mod. It is not affiliated with or endorsed by Mojang, Microsoft, Google/YouTube, Netflix,
Hulu, Crunchyroll or Amazon.

- Players: [docs/player-quick-start.md](docs/player-quick-start.md)
- Server owners: [docs/admin-guide.md](docs/admin-guide.md)
- What works where: [docs/provider-support.md](docs/provider-support.md) and [CHANGELOG.md](CHANGELOG.md)

## What is implemented

| Area | Summary | Status |
| --- | --- | --- |
| Televisions | 6 models, multi-block (1x1 to 3x2), floor and wall mounting, atomic placement, exactly-once breaking, repair and orphan cleanup, comparator output | done, GameTests |
| Remote | Pairing by persistent identity, range/dimension checks, full remote GUI, key binding | done, GameTests |
| Sessions | Server-authoritative timeline, roles and ACL, leases, revisions, scheduled starts, timing broadcasts, queues, auto-pause, checkpoints | done, GameTests |
| Channels | Datapack channels, admin channels, `/otetv` commands, server source policy | done |
| Direct media | Bundled demo, local files, HTTPS progressive, unencrypted HLS, captions, lip sync on the audible clock | done on Linux (worker harness, in-world smoke test) |
| YouTube | Official IFrame player in a native CEF 156 worker with the Chromium sandbox on, first-party wrapper identity, guarded network proxy | done on Linux (harness, in-world); Windows not built |
| Subscription services | Netflix, Hulu, Crunchyroll, Prime Video | external browser only, by design |
| Rendering and audio | Per-TV textures, letterboxing, period effects, captions, enlarged viewing, positional OpenAL audio | done, screenshots in the smoke test |
| Privacy and security | Per-client consent, LAN and file grants, SSRF-safe fetching, worker isolation and integrity, redacted diagnostics | done |
| Runtime installation | Manifest or file install with checksum, safe extraction, atomic activation and rollback | done; no hosted bundles |

Details, evidence and environments: [docs/feasibility.md](docs/feasibility.md), [docs/test-results.md](docs/test-results.md).

## Building

Requirements: JDK 17. Everything else is fetched by the Gradle wrapper (Gradle 8.8, ForgeGradle 6, Forge 47.4.23).

```sh
./gradlew build                 # mod jar, core tests, media worker, side-boundary check
```

The mod jar is `build/libs/otetv-<version>.jar`. It contains the core library and the media worker
(`otetv_workers/otetv-media-worker.jar` with its SHA-256 in `workers.properties`). Versions are pinned in
`gradle.properties`.

Data generation (recipes, loot tables, tags, advancements into `src/generated/resources`):

```sh
./gradlew runData
```

Art and media are generated by scripts and committed: `tools/assets/generate_assets.py` (models, textures, sounds,
language), `test-fixtures/generate_media.py --demo` (the original demo clip; needs ffmpeg), and
`tools/assets/generate_gametest_structures.py`.

### Browser worker (optional, Linux)

```sh
python3 runtime-packaging/fetch_cef.py          # pinned CEF, SHA-1 verified (about 330 MB download)
cmake -S browser-worker -B browser-worker/build -G Ninja -DCMAKE_BUILD_TYPE=Release -DOTETV_WORKER_VERSION=0.1.0
cmake --build browser-worker/build
python3 runtime-packaging/package_browser_worker.py --url https://<your host>/<file>.zip
```

This produces a runtime bundle and manifest in `runtime-packaging/out/` (nothing is uploaded). Players install it
from the TV's runtime screen with **Install from file**, or from your URL with a manifest; see the admin guide.

## Running in development

```sh
./gradlew runClient            # dev client (run/)
./gradlew runServer            # dedicated server (run-server/; accept the EULA there first)
./gradlew runGameTestServer    # all 27 GameTests on a headless server, exits with the failure count
./gradlew :core:test           # 149 unit tests
tools/run_smoke_test.sh        # in-world smoke test with screenshots (run/screenshots/otetv_smoke_*.png)
tools/run_smoke_test.sh youtube  # adds the YouTube phase (needs runtime-packaging/out)
```

Worker harnesses drive each worker through the real IPC without Minecraft:

```sh
java -cp core/build/classes/java/main tools/worker-harness/WorkerHarness.java \
     media-worker/build/libs/otetv-media-worker.jar FILE "$PWD/test-fixtures/media/theora_vorbis.ogv" 8 /tmp/frame.png
java -cp core/build/classes/java/main tools/worker-harness/BrowserHarness.java \
     browser-worker/build/Release/otetv-browser-worker M7lc1UVf-VE 45 /tmp/youtube.png
```

On a machine with these tools, the repository's helper `gradlew-quiet.sh <dir> <task>` gives the same results with
quieter output.
